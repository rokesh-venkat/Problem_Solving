## 💡 Tips for Competitive Programming

### Best Practices Used in This Repo

1. **Time Complexity Analysis** — O(n) notation in comments
2. **Space Optimization** — Memory-efficient solutions preferred
3. **Clean Code** — Readable, well-commented solutions
4. **Multiple Approaches** — When applicable, different solutions shown
5. **Test Cases** — Included for complex problems

### How to Approach Each Problem

```
1. Understand the problem statement
2. Identify input/output format
3. Think of brute force approach
4. Optimize time & space complexity
5. Code & test with examples
6. Submit & iterate if needed
```

### Learning Path Recommended

```
Beginner  → Arrays, Strings, Basic Math
↓
Intermediate → Sorting, Searching, Hash Tables
↓
Advanced  → Trees, Graphs, Dynamic Programming
↓
Expert    → Greedy, Backtracking, Advanced DP
```

## 📝 Notes & Tips

### Problem-Solving Approach

1. **Read Carefully** — Understand constraints & edge cases
2. **Think First** — Plan before coding (pseudocode helps)
3. **Code Clean** — Use meaningful variable names
4. **Test Thoroughly** — Edge cases, large inputs, negative cases
5. **Optimize** — Improve time/space if solution is correct
6. **Learn** — Understand why your solution works

### Common Mistakes to Avoid

- ❌ Integer overflow (use `long long` in C++)
- ❌ Off-by-one errors in loops
- ❌ Not considering edge cases (empty input, single element)
- ❌ Inefficient algorithms (TLE - Time Limit Exceeded)
- ❌ Incorrect data type usage
- ❌ Not reading problem constraints carefully

### Templates Available

This repo includes templates for:
- ✅ C++ competitive programming setup
- ✅ Fast I/O techniques
- ✅ Common data structure implementations
- ✅ Algorithm templates (BFS, DFS, DP, etc.)
